# AI Code Review Evaluator

A JavaScript, Java, and Python toolkit for evaluating code quality, detecting common defects, and generating transparent evaluation reports.

## Features

- Evaluate code against defined rules.
- Detect common coding defects.
- Score code using a transparent evaluation rubric.
- Generate JSON evaluation reports.
- Support JavaScript, Java, and Python code.

## Technologies

- JavaScript (Node.js)
- Java
- Python
- JSON

## Project Status

Prototype in development. The initial version uses rule-based checks; AI model integration may be added later.
